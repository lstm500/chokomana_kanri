# ちょこまな みまもり

集約アプリ「ちょこまな | まなびのホーム」の分析・管理を、保護者用の「みまもり」に移植した差し替え版です。移植元は `app(20261124-152200).py` です。

## 反映手順

1. 既存の Supabase プロジェクトの SQL Editor で `mimamori.sql` を実行します。既存の管理アプリ用テーブルがある環境向けの移行SQLです。学習記録を引き継ぎます。
2. 同じプロジェクトの既存 Edge Function `chokomana-watch` の `index.ts` を差し替えてデプロイします。独自セッション認証を使うため、現在の `verify_jwt = false` を維持します。
3. 既存の管理アプリのリポジトリで `app.py` を差し替えます。`requirements.txt` は起動依存の確認用に同梱しています。

## 分析・管理の操作

- **要確認と修了推奨**は、学習アプリの絞り込みにかかわらず全7アプリから表示します。要確認の「詳細を確認」から、直近5回の完了記録で誤答が多い問題を確認できます。
- **単元別の学習記録**では、学習アプリ、並び順、修了状態を選べます。累計正答率と学習回数、完了した学習の5回・15回平均を表示します。小さい画面では表を横にスクロールでき、単元名は左端に固定されます。
- **重点単元と修了認定**は、管理用PINで解除してから変更できます。修了すると同じ単元の重点が外れます。変更は各学習アプリ、集約アプリと同じ修了・重点データに保存されます。
- **きょう やること**を開くと、教科配分の比率と自動出題する学習アプリを変更できます。
- **誤答へのAI提案**を使う場合は、Edge Functions の Secrets に `OPENAI_API_KEY` を設定します。任意の `OPENAI_MODEL` の既定値は `gpt-4.1-mini` です。キー未設定時も誤答の集計と対策の例を表示します。

## 確認

集約アプリと管理アプリを同じアカウントで開き、両方の「記録を更新」を押すと、各単元の件数・正答率・修了状態を照合できます。

サンプルの7教科・68単元で、集約アプリのPython集計と管理アプリのTypeScript集計の一致を確認しました。模擬データで、認証、ページ分割、誤答詳細、PINによる保護、重点・修了の更新、同時変更後の再読み込みを確認しました。実ブラウザーでの表示確認、既存Supabaseへの適用・デプロイ、実データでの照合は未実施です。
